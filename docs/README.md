# Docs

Specs come first. Code is built to match them. If the code and a spec disagree, fix one of them in the same change.

- `intent.md` – goal, scope, risks, success criteria
- `specs/` – one file per component
  - `spec-llm-provider-interface.md`
  - `spec-generate-query.md`
  - `spec-connection.md`
  - `spec-schema-extraction.md`
  - `spec-query-validation.md`
  - `spec-query-execution.md`
  - `spec-api.md`
  - `spec-ui.md`
  - `spec-benchmark.md`
- `reviews/spec-review.md` – cross-check of all specs, with the build order
